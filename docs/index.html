⌨Hotkeys anywhere

Press a combo with Ctrl, Alt, Shift or Win from any program and it fires. Each hotkey can do several things in a row.

🚀Launchers

Drag icons, files, folders and web links in, save, and get one Desktop shortcut with your own icon that opens them all.

⚙What a hotkey can do

  • Open programs, files, folders, websites
  • Paste saved text
  • Lock, sleep, show desktop, hidden files…
  • Music and volume keys
  • Mouse clicks and waits
  • Open a workspace

🪟Workspaces

Arrange your windows once, save it. One click or hotkey reopens everything in the same spots and sizes.

🔎Quick Search

Press Win+Alt+Space anywhere, type a few letters: apps, files (via Everything), hotkeys, launchers, workspaces, websites.

✍Snippets

Type a short code like ;sig in any program and it turns into your saved text, with {date}, {time} and more.

🗂Stay organized

Categories you can rename, drag to rearrange, search, and a printable cheat sheet of every hotkey.

🎨Your colors

Light or dark, five color themes and any accent. Tap the sun/moon; hold it for colors.

💾Backups

Export everything to one file and import it back. Brings in hotkeys from the old Stardock Keyboard Launchpad, too.

Getting started

  1. Download and put LaunchPad.exe anywhere you like, then double-click it.
  2. Hotkeys tab: click Add, press your keys, pick what it should do.
  3. Launchers tab: drag things in, click Save.
  4. Closing the window keeps it running in the tray. Turn on Start with Windows from the tray icon.

Coming from Keyboard Launchpad? LaunchPad offers to bring your hotkeys in the first time it starts. Close Keyboard Launchpad so the keys are free.
